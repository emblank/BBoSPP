# The Big Book of Small Python Projects

## Description
This repo is documentation for my personal journey through Al Sweigart's
"The Big Book of Small Python Projects." The goal here is to work with
Python, hands-to-keyboard, on a more consistent basis.

A little context...
I did a mid-career pivot into cybersecurity and found myself being
more interested in programming languages and development. Security is
a big part of my background, so I'll stick here, but I want to improve
my coding skills and deepen my fluency in Python.

I learned a lot of foundations before the big AI boom / push, but now
with such ease of access to generative AI, I'm finding my skills stagnating
and I'm not growing as a developer the way I should. This is my response.
I'm building structure for myself and holding myself publicly accountable.

I'm the kind of person who can get lost in the theoretical learning;
so, I need some structure to help me build the muscle memory. Platforms
and tutorials online are difficult to me because I still want to build
and make things work and have function and purpose. But I'm also not
prone to creation _ex nihilo_; so, some structured projects it is!

## Outputs
1. Code for the Projects
2. Notes from the building and iterating processes.
3. Ideas for further iteration
4. Ideas for other builds
5. Something else, probably
